# Exercício – Banco de Dados Relacional (MySQL)

Este repositório contém exercícios práticos de **Banco de Dados Relacional**, utilizando **MySQL**, desenvolvidos como parte do aprendizado de modelagem e manipulação de dados.

## 📂 Estrutura do Repositório

O projeto é composto por **três arquivos SQL**, cada um representando um cenário diferente:

- **RH**  
  Estrutura de banco de dados para gerenciamento de funcionários, incluindo criação de tabela, inserção de dados, consultas e atualização de registros.

- **E-commerce**  
  Modelagem de uma tabela de produtos, com atributos como nome, categoria, preço e estoque.

- **Escola**  
  Criação de uma tabela de alunos, com informações como turno, ano escolar e média final.

## 🛠 Tecnologias Utilizadas

- MySQL
- SQL (DDL e DML)
- Git e GitHub

## 🎯 Objetivo

Praticar os conceitos fundamentais de:
- Criação de bancos de dados e tabelas
- Inserção de dados
- Consultas com filtros
- Atualização de registros
- Boas práticas em SQL

## ▶️ Como utilizar

1. Abra o MySQL ou um gerenciador de banco de dados (MySQL Workbench, DBeaver, etc).
2. Execute os scripts SQL conforme o cenário desejado.
3. Analise as tabelas e consultas criadas.
